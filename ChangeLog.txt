## [0.4.0] - 2026-09-05

### Added

- **Level-1 verifier (`verify_slim_level1`).** Degree-2 sumcheck with MLE-of-product
  residual check: `fr_r - u·cz_r - er_r == final_claim == 0`. Fixes the earlier
  `az_r·bz_r` completeness failure for honest relaxed folds.
- **PCS openings — circuit-backed OP (`recompute_circuit_evals`).** Verifier
  evaluates `MLE(tt_E)(r) == er_r`, binding claimed evaluations to the committed
  witness/error vector.
- **Complete verifier (`verify_full`).** Combines SC + L1 + OP + optional norm
  audit + fold re-verification. Knowledge soundness under an untrusted prover.
  Public API: `FullVerifyOutput { steps, transcript_final, norm }`.
- **Fold re-verification (FV, soundness item #29).** `Level1SlimProof.fold_log`
  carries per-fold-step pre-fold instances + cross-term commitments (`com(T)`);
  `verify_fold_log` recomputes Fiat-Shamir challenges and re-checks the NIFS
  homomorphic fold relation per step. CBOR `FORMAT_VERSION` bumped to 2.
- **Norm enforcement (audit-only).** `norm.rs` with Option A (range/bit-decomposition)
  and Option B (JL/sketch) per-step pre-fold witness shortness certificates.
  CLI flags `--norm-range` / `--norm-jl` (compress) and `--norm-*` + `--circuit`
  + `--steps` (verify). Re-fold ground-truth audit in `verify_level1_norm`.
- **Benchmarks for complete verifier + norm modes.** VRF 254 steps,
  BLS12-381/Pedersen: slim 0.4 KiB (0.3 ms), level-1 1.4 KiB (69 ms),
  norm-range 34 KiB (142 ms), norm-JL 42 KiB (215 ms).
- **Property tests:** 3 FV proptests (tampered acc witness / cross-term commit /
  fold-log length mismatch), fold-log CBOR round-trip, level-1 norm E2E tests.
- `nifs::fold_with_log` exposes the per-fold cross-term commitment.
- `prop_hash_commit_seed_separation` fix: exclude all-zero vector (expected
  `A·0 = 0` for any seed).

## [0.3.0] - 2026-08-29

### Added

- GitHub Actions workflows: CI (Rust, Aiken, CIP-197 equivalence) and release automation.
- Refined Rust, Aiken and e2e testing; `cargo fmt`/`aiken fmt` checks part of CI.
- Investigation of two research papers.

## [0.2.0] - 2026-08-28

### Added

- Slim sumcheck proofs (~0.4-2.5 KiB) for on-chain verification, with an
  explicit audit trail via the full sumcheck proof.
- NIFS IVC folding of `N` identical step circuits into a single O(1)
  accumulator - transparent, no trusted setup, no pairings.
- Three runtime-selectable commitment schemes: Pedersen, SIS, Hash.
- Six elliptic curves: BLS12-381, BN254, Pallas, Vesta, Grumpkin, Bandersnatch.
- `nova-slim` CLI (`params`, `fold`, `compress`, `verify`) with compact,
  versioned CBOR serialization.
- Aiken on-chain (Plutus V3) verifier under `cardano/nova-slim-verifier`.
- CIP-197 proof-of-concept with e2e equivalence testing of the two documented
  ways (`cardano/cip197/scripts/e2e_equivalence.sh`) plus a Rust CLI e2e test.
- Parallel optimizations (`--opt parallel`).
- Documentation: repo README, prover and verifier READMEs, CIP-197
  README/E2E walkthroughs.
